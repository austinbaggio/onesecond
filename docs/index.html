One Second

Breathe before Instagram, Facebook, or any app opens.

Breaths per pause

Apps to slow down

Step 1: Make the shortcut (once)

Open the Shortcuts app, tap +, name it One Second, and add these actions in order. Search for each one by name.

  1. Get File from Folder. Folder: Shortcuts. Path: onesecond.txt. Tap the arrow, turn off Error If Not Found.
  2. If. Leave it as File has any value.
  3. Delete Files. Drag it just under If. Tap the arrow, turn off Confirm Before Deleting.
  4. Text. Drag it under Otherwise. Type ok.
  5. Save File, under the Text. Tap the arrow, turn off Ask Where to Save, set the path to onesecond.txt, turn on Overwrite If File Exists.
  6. Open URLs, under Save File. Paste this link:

Step 2: Make the automation (once)

  1. In Shortcuts, tap Automation, then +, then App.
  2. Tap Choose and select . Check Is Opened. Pick Run Immediately. Tap Next.
  3. On the next screen, pick One Second from your shortcuts. It is the shortcut from Step 1, not an app. If it isn't listed, tap New Blank Automation, add Run Shortcut, and choose One Second.

Done. Open Instagram and the breathing screen jumps in front. To add another app later, edit the automation and select it too.
