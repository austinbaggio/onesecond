  1. Tap Automation, then +, then App.
  2. Choose , check Is Opened, pick Run Immediately, tap Next, then New Blank Automation.
  3. Add Get File from Folder. Folder: Shortcuts. Path: . Tap the arrow and turn off Error If Not Found.
  4. Add If. Set it to File has any value.
  5. Under If, add Delete Files (delete the File). Tap the arrow and turn off Confirm Before Deleting.
  6. Under Otherwise, add Text and type ok.
  7. Under that, add Save File. Tap the arrow, turn off Ask Where to Save, set the path to in Shortcuts, and turn on Overwrite If File Exists.
  8. Under that, add Open URLs and paste your link.
  9. Tap Done.
